Bien démarrer

Où sont mes données ?

Cette édition autonome conserve vos données sur votre appareil. Elle ne nécessite ni compte applicatif ni serveur partagé. Chaque appareil possède sa propre base ; aucune synchronisation automatique ni collaboration entre utilisateurs n’est incluse.

Comment créer une sauvegarde ?

Ouvrez Administration, puis Données. Créez une sauvegarde, puis utilisez Exporter pour conserver une copie dans un emplacement de votre choix. Protégez l’export avec un mot de passe et gardez-le en lieu sûr.

Une copie conservée uniquement sur le même appareil ne protège pas contre sa perte. Conservez aussi une copie ailleurs.

Comment transférer les données sur un autre appareil ?

Exportez une sauvegarde avec un mot de passe, puis transférez ce fichier sur l’autre appareil. Dans Mainty, utilisez Importer, saisissez le mot de passe, puis choisissez Restaurer.

Une restauration remplace les données locales ; elle ne fusionne pas deux bases. Une copie de récupération est créée avant la restauration. Sauvegardez toujours vos données actuelles avant un transfert.

J’ai oublié le mot de passe d’un export

L’assistance ne peut pas récupérer ce mot de passe. Si vos données sont encore présentes dans Mainty sur l’appareil d’origine, créez un nouvel export avec un nouveau mot de passe.

Puis-je travailler sans Internet ?

Les données de l’édition autonome sont locales. Le téléchargement de l’application, certains services Apple et l’ouverture de liens externes nécessitent une connexion. Un transfert via un fournisseur cloud dépend également de sa connexion.
